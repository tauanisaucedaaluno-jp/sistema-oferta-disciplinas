# Documentation Co-authoring Workflow

Use this skill to assist the user in writing high-quality technical documentation.

## Workflow Steps

1. **Information Gathering**: Ask the user for the core objective of the document, the target audience, and any key points that must be included.
2. **Outline Creation**: Propose a structured outline (Table of Contents) based on the gathered information. Wait for user approval or adjustments.
3. **Drafting - Section by Section**: Draft the content one section at a time, allowing the user to review, critique, and modify each part before moving on to the next.
4. **Review and Refine**: Once the draft is complete, do a full review for consistency, tone, and clarity.
5. **Finalization**: Format the final document in clean Markdown (or the requested format) and present it to the user.
